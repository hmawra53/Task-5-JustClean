# 🧹 JustClean - Task 5

## 📌 Overview

JustClean is a responsive multi-page maid booking website enhanced with an interactive **Cleaning Service Catalog and Booking Cart**, developed as part of **Task 5** during my **Full Stack Web Development Internship** at **Maincrafts Technology**.

This task focused on extending the existing JavaScript and LocalStorage functionality by implementing a dynamic **service catalog and booking system** with real-time search, category filtering, sorting, pagination, service details, cart management, and booking confirmation.

---

## ✨ Features

- 🏠 Responsive multi-page website
- 👨‍🔧 Professional maid booking platform interface
- 🧹 Dynamic cleaning service catalog
- 🔍 Search services dynamically by name
- 🔽 Filter services by category
- ↕️ Sort services by price and name
- 📄 Pagination for navigating through available services
- 📋 View detailed service information through a modal
- ➕ Add cleaning services to the booking cart
- ➕ Increase or decrease service quantities
- 🗑️ Remove individual services from the cart
- 🧹 Clear all selected services from the cart
- 🛒 Dynamic cart item count
- 💰 Automatic booking total calculation
- 💾 Store booking cart data using LocalStorage
- ✅ Confirm selected cleaning services
- 🆔 Generate a unique booking ID after confirmation
- 💾 Store confirmed bookings using LocalStorage
- 🔄 Dynamic updates to the service catalog and booking cart
- 📱 Responsive design for desktop and mobile devices
- 🎨 Clean and modern user interface
